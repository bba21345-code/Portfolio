# Neeraja Bevara — Portfolio

A static, responsive portfolio built with HTML, CSS, and JavaScript. No React, npm, or build step required.

## Files
- `index.html`
- `style.css`
- `script.js`

## Publish on GitHub Pages
1. Upload these three files to the root of your GitHub repository.
2. Make sure the home page is named exactly `index.html`.
3. Go to **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the deployment and refresh your Pages URL.

Important: paste only the code inside each file. Do not include Markdown fences such as ```html or ```css.

Replace `YOUR-GITHUB-USERNAME`, `YOUR-LINKEDIN-USERNAME`, and `YOUR-EMAIL@example.com` in `index.html`. Review education details before publishing.
